# Security

A vulnerability in this fork's own patches or in how it builds and
publishes its releases: report it to security@airdress.co, or privately
through this repository's security advisories. Please do not open a public
issue.

A vulnerability in MapLibre Native itself, including in the globe pull
request this fork carries: report it to upstream, as
[maplibre/maplibre-native's security policy](https://github.com/maplibre/maplibre-native/security/policy)
describes. This fork takes upstream's security fixes within days of their
release.
